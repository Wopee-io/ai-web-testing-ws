# Prompt 3: Executive summary report from YouTrack data

Use the **YouTrack MCP** server.

You are preparing a one-page executive summary of our quality status for a management demo. Fetch everything live via MCP - no invented numbers.

1. `get_current_user` + `find_projects` - confirm the target project (ask me if there is more than one).
2. Gather the data:
   - `search_issues` with `project: <KEY> #Unresolved` (all open) and `project: <KEY> #Resolved` (closed), plus `project: <KEY> updated: {minus 14d} .. Today` for recent activity
   - For the top open issues, `get_issue` to pull Priority, Assignee, and State
   - `get_issue_fields_schema` to learn the real Priority/Type values before bucketing
3. Produce the report in this shape:

   ```markdown
   # Quality Status - <Project name> - <date>

   ## Headline
   [One sentence: overall state in plain business language]

   ## Numbers at a Glance
   | Metric | Value |
   |---|---|
   | Open issues | ... |
   | Resolved (all time) | ... |
   | Touched in last 14 days | ... |
   | Open bugs by priority | Show-stopper: n / Critical: n / Major: n / Normal: n / Minor: n |
   | Unassigned open issues | ... |

   ## Top 3 Risks
   [Highest-priority open issues, one line each: ID, summary, why it matters to the business]

   ## Trend & Momentum
   [What the 14-day activity says: are we closing faster than opening?]

   ## Recommendation
   [One concrete next step for the team]
   ```

4. Keep it demo-friendly: round numbers, plain language in Headline/Risks/Recommendation (no tool names, no IDs jargon beyond issue keys), tables aligned.
5. Present the report in chat only - do **not** create or modify anything in YouTrack.

Rules: English only, fetch every number via MCP, state "no data" honestly where the project is empty rather than inventing figures.
