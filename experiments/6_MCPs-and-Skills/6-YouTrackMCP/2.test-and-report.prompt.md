# Prompt 2: Test, then file the bug in YouTrack

Use the **Playwright MCP** and **YouTrack MCP** servers together.

1. Open <https://foodora.lovable.app/> with Playwright MCP.
2. Run a short exploratory pass: filter restaurants by **Pizza**, open one restaurant detail page, add an item to the cart, go to the cart. Take a screenshot at each step.
3. Note every problem you hit (error, broken layout, dead link, slow page, confusing wording).
4. For the most severe problem:
   - Search YouTrack first (`search_issues`) so you do not create a duplicate.
   - Draft an issue: summary, description with steps to reproduce, expected vs actual behaviour, environment.
   - Show me the draft and wait for my approval.
5. After I approve, create it with `create_issue` and add the screenshot observations as a comment (`add_issue_comment`).

Rules: English only, one issue per problem, never create an issue with an empty description.
