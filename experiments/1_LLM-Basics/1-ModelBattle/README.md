# Experiment 1.1: Blind Model Battle - Screenshot → UAT Test Cases

> **Time:** ~10 min (1 run + group discussion)

## The Concept

Can you recognize a better model purely by its output? Arena runs your prompt through two **anonymous** models side by side. You vote for the better answer first - only then does it reveal which model wrote which. No brand bias, just output quality.

## Steps

1. Navigate to [arena.ai](https://arena.ai/)
2. Upload [`files/foodora-homepage.png`](files/foodora-homepage.png) - a screenshot of the Foodora food-delivery homepage
3. Type this into the *Ask me anything* field and submit:

   > *Generate high-quality UAT test cases.*

4. Read both answers side by side and **vote for the winner**
5. Check which models you were comparing after the reveal

## Discussion Points

- Did you pick the answer from the objectively stronger model? Check the [leaderboard](https://arena.ai/leaderboard) - or did a smaller model beat a frontier one?
- The prompt was deliberately lazy - one sentence, no context. How would you improve the quality of the generated test cases? (Role, output format, acceptance criteria, scope, priorities...)
- Do you have hands-on experience with any test case generation tools? If so, share it with the group.
